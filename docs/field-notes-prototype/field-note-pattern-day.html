What is an LLM evaluation harness?

61 answers out of 64 were right. The run was declared a failure.

Two of the three misses sat in the safety tier. A pass rate with no threshold attached is a number, not a decision. This note explains what turns it into one.

Peak · the proof in ten seconds · recorded run, Lore

An engine was burning oil exactly at the limit set by the maintenance manual. The manual says that is already too high. Lore said it was normal.

1 · The answer

"Normal. Record it, no further action required."

Fluent, confident, and wrong.

2 · The graders

FAIL. It contradicts the manual. The release is blocked.

No unit test sees this: the code ran perfectly.

3 · The code

If an answer contradicts the manual, one correction; if it still does, the manual's verdict ships.

The rule is held by code, not asked for in a prompt.

Field Notes · For deciding what a model may do on its own · 6 min · revised 5 times

Where should an agent's responsibility end?

A wrong forecast is absorbed. A wrong action reaches a guest.

So the line between components is drawn where the consequence changes, not where the technology does.

Peak · tomorrow's breakfast, the evening before · illustrative scenario

The evening before, Aetherix suggests tomorrow's breakfast staffing to the hotel's F&B manager. The manager has the last word: from that reply on, the system decides nothing.

The message the manager reads

How many guests to expect at breakfast tomorrow, how sure it is, and how many staff to plan.

"I'd say 79 covers instead."

What the reply is

A decision, recorded next to the recommendation. The manager weighs what the system cannot see: a sick waiter, a group check-in.

Field Notes · For deciding what your product learns from · 6 min · revised once

Whose truth is the ground truth?

An AI product is only as honest as the answer it learns from.

Choosing that answer is a product decision, made before the data arrives.

Peak · the easiest number to collect

A yes is not a right.

Same evening · declared

The manager approves.

It measures agreement. A manager can approve a wrong forecast and reject a right one.

Next day · observed

The real covers arrive.

Only this says which forecast was right.

A product that simply repeated last Tuesday's numbers would be approved often, and teach nothing.
